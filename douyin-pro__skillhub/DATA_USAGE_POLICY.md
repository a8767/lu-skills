# 🎵 抖音 Skills 数据使用政策

**适用范围**：maxhub-douyin | **生效日期**：2026-07-10

> 本文件是[项目级数据使用政策](../../DATA_USAGE_POLICY.md)的平台专属补充。如两者冲突，以项目级政策为准。

---

## 1. 数据来源声明

本 skill 通过 MaxHub API（`https://www.aconfig.cn`）获取 **抖音** 平台数据，该服务为**第三方数据聚合服务**，并非 抖音 官方 API。

- 本 skill **不持有、不存储**任何平台数据
- MaxHub API 的数据获取方式**未获得 抖音 官方授权**
- 本项目对数据获取的合法性**不作任何明示或暗示的保证**

---

## 2. 合法使用场景

- **公开数据分析**：分析 抖音 公开可见的内容趋势
- **竞品研究**：在合法合规前提下进行市场竞争分析
- **内容创作辅助**：辅助创作者了解行业趋势和受众偏好
- **学术研究**：用于经伦理审查委员会批准的学术研究

---

## 3. 禁止使用场景

### 3.1 违反法律的行为

| 禁止行为 | 相关法律 |
|---|---|
| 爬取、存储、交易他人个人信息 | 《个人信息保护法》第2条 |
| 批量采集平台数据用于商业竞争 | 《反不正当竞争法》第12条 |
| 绕过平台技术保护措施 | 《计算机信息网络国际联网安全保护管理办法》 |
| 刷量、刷粉、虚假宣传 | 《反不正当竞争法》第8条 |
| 规避实名身份验证 | 《网络安全法》第24条 |
| 电信诈骗相关活动 | 《反电信网络诈骗法》 |
| 侵犯他人通信自由和通信秘密 | 《宪法》第40条 |

### 3.2 违反平台服务条款的行为

- 使用未经授权的自动化工具访问平台数据
- 伪造设备信息、会话标识或反爬签名
- 批量提取用户标识符用于关联分析
- 使用他人登录凭证（cookie/token）访问非本人数据
- 代发私信或消息

### 3.3 侵犯他人权利的行为

- 收集、存储未公开的个人信息（联系方式、位置、社交关系）
- 将他人 UGC 内容用于未经授权的商业用途
- 侵犯他人著作权（如批量下载视频用于二次分发）

---

## 4. 数据保护要求

- **最小必要原则**：仅采集与使用目的直接相关的最少数据
- **知情同意原则**：处理个人信息前应获得数据主体的明示同意
- **目的限制原则**：不得将数据用于收集时未告知的目的
- **存储限制原则**：个人信息应在达成目的后及时删除

### Cookie/凭证安全

- 传入 cookie 等同于暴露用户登录凭证，存在被滥用的风险
- **禁止**传入他人账号的 cookie 或 session 凭证
- 建议使用独立测试账号，定期轮换 API Key

### 跨境数据传输

- 涉及海外数据访问时需遵守《数据安全法》第31条和《个人信息保护法》第38条
- 关键信息基础设施运营者收集的个人信息应在中国境内存储
- 确需向境外提供的，应通过国家网信部门组织的安全评估

---

## 5. 数据主体权利

- **被遗忘权**：如数据处理涉及个人信息，数据主体有权要求删除
- **数据访问权**：数据主体有权知悉其个人信息是否被处理
- **数据处理透明度**：所有数据采集行为应向数据主体明示

---

1. **使用者责任**：使用本 skill 的所有法律合规责任由使用者自行承担
