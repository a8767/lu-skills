# 抖音 合规审查清单

**使用前必读**：在使用 抖音（douyin-pro）skill 之前，请逐项确认以下合规检查项。任何一项不通过，即不应使用该 skill。

---

## 1. 合法性评估

| # | 检查项 | 通过 | 不通过 |
|---|---|---|---|
| 1.1 | 数据使用目的是否合法（非诈骗、非不正当竞争、非侵权） | ☐ | ☐ |
| 1.2 | 是否已阅读并理解 [DATA_USAGE_POLICY.md](./DATA_USAGE_POLICY.md) | ☐ | ☐ |
| 1.3 | 是否已评估数据获取方式的法律风险（非官方 API） | ☐ | ☐ |
| 1.4 | 是否确认不涉及任何已移除的高风险端点（刷量、反爬、会话伪造等） | ☐ | ☐ |
| 1.5 | 是否确认不将数据用于违反《网络安全法》《数据安全法》《个人信息保护法》的目的 | ☐ | ☐ |
