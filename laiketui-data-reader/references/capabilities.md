# laiketui-data-reader 能力说明（实测，2026-07-15）

> 本文档基于 **真实浏览器测试（2026-07-14~07-15，青石峡漂流 / 驭龙峡漂流门店管理员账号）** + **脚本源码** 整理。
> 凡标注「实测」的，均为本会话内已验证可跑通或已踩坑确认；未标注的来自 SKILL.md 声明与代码静态分析。
> 配套脚本：`scripts/aggregate.py`、`scripts/normalize.py`；字段映射见 `references/modules.md`；复盘数据模型见 `references/review-schema.md`。

## 一、能做到的（功能与能力）

### 1. 浏览器自动化读取（核心引擎 = agent-browser / CDP）
- **复用用户已登录的 Chrome 会话态**抓取来客后台与生意经数据中心数据。
- 已验证可用的原子能力：`connect`、`open`、`snapshot`、`click`、`fill`、`eval`、`cookies get`、`screenshot`、`tabs`。
- 支持启动带 `--remote-debugging-port` 的 Chrome（`--user-data-dir` 持久登录态），并 `connect <port>` 接管。
- **前提**：目标 Chrome 必须已由用户手动登录过来客/生意经；本技能**不自动输入账号密码或验证码**。

### 2. 多商户切换（代运营多客户场景，实测跑通）
- 入口：来客后台右上角公司名 → 下拉「切换商户」→ 弹「切换公司」对话框 → 搜索商户名 → 选中 → 确认。
- 实测成功：郑州爪娃岛商贸有限公司 → 驭龙峡漂流（URL `groupid` 从 `1776747848611853` 变为 `1867591074882572`）。
- 可靠自动化方案：**`eval` 按文本 `click()`**（绕过 `@eN` ref 失效）；搜索框支持模糊匹配；列表项需**先选中**底部才出现「确认」按钮。
- 切换后页面完整刷新，需重新 `snapshot` 定位元素（ref 每次变化）。

### 3. 生意经数据中心 + 来客独立模块的数据读取
数据来源覆盖两大后台：

| 来源 | 域名 | 可读取内容 | 验证状态 |
|------|------|------------|----------|

| 生意经流量 | life-data.cn | 总曝光、门店页访问、**流量来源表（直播/视频/搜索各自的曝光/成交/核销/转化率）** | 实测 |
| 生意经内容分析 | life-data.cn | 直播（成交/核销/退款/时长/场次/观看/转化率）、视频（成交/播放/种草价值/券数） | 实测 |
| 生意经人群资产 | life-data.cn | 新客/老客成交数、复购率、人群画像 | 实测 |
| 生意经投放分析（本地推） | life-data.cn | 消耗、投放成交、**综合/直播/非直播 ROI**、Top商品 | 实测 |

- **时间范围**：生意经「流量」页有「自然月」快捷键（实测可用，切后核心数据/体裁均为 07-01~07-14 口径）；「自定义」日历**已自动化打通**（点统计周期图标→自定义→双月面板选起止，详见 `references/user-taught-methods.md` 方法一），可设跨月长区间与精确自然周。
- 两处数据互相验证：直播专业版 7月82场总成交 ¥46,958 与生意经直播成交 ¥47,758 高度吻合 ✅。

### 4. 数据提取与规整（scripts/normalize.py，仅标准库）
- **输入类型**（已支持）：
  - `eval` 得到的二维数组 JSON（`[["表头"...]],["数据"...]]`）；
  - 形如 `{"headers":[...],"rows":[[...]]}` 的 JSON；
  - 含 `<table>` 的 HTML 文件（从 `browser-use get html` 或页面另存得到）。
- **输出格式**：
  - CSV（默认，`utf-8-sig` 带 BOM，Excel 直接打开不乱码）；
  - Excel（`.xlsx`，需 `openpyxl`；**按 `store_name` 拆分多 sheet**；缺失则回退 CSV）。
- **字段标准化**：30+ 中文表头 → 英文键（如 商品名称→`product_name`、退款率→`refund_rate`），忽略大小写/空格/标点。
- **数值化**：自动去除「万/元/¥/%/逗号」，识别「万」并 ×10000；率类、金额、计数类自动转数值。

### 5. 四维度复盘聚合与报告（scripts/aggregate.py，仅标准库）
- **周期类型**：`week` / `month` / `quarter` / `year`（自然周/自然月/自然季/自然年；`--completed` 取上一完整周期）。
- **子命令**（源码已实装）：
  - `period`：计算某参考日下的周期起止与 key；
  - `collect`：把一次抓取的指标写成 canonical 记录（`data/<client>/records/<key>.json`）；
  - `rollup`：从细周期聚合出粗周期（周→月→季→年）；
  - `review`：生成完整复盘报告（**.md 五章 + .csv 扁平数据**）；
  - `query`：按 客户/周期类型/起止日期 灵活查询已存记录（可导出 CSV）。
- **四类数据模型**（复盘必备，缺一类即不完整）：
  1. **统计（stats）**：本周期核心指标（25+ 指标键，见 `review-schema.md`）；
  2. **对比（comparison）**：环比 `qoq`（vs 上一相邻周期）+ 同比 `yoy`（vs 去年同期），缺失历史时由脚本自动计算；
  3. **趋势（trend）**：最近 N 个子周期序列（周8/月12/季8/年5）；
  4. **目标完成度（goal）**：来自 `config/targets.json`，完成率 = 实际/目标。
- **率类指标自动推导**：核销率=核销券/成交券、退款率=退款额/GMV、复购率=复购人/新客。
- **依赖**：仅 Python 标准库；Excel 输出才需可选 `openpyxl`。

### 6. 飞书文档交付（配套 lark-cli，实测）
- 用 `lark-cli docs +create / +update --command overwrite --doc-format markdown` 把复盘报告写入/覆盖飞书文档（user 身份，实测多次成功，revision 持续递增）。

### 7. 安全边界
- 默认**只读不改写**（不做上架/改价/退款等写操作）；用户明确要求写操作时二次确认后执行。
- 连接浏览器、读写本地文件、调用 lark-cli 均在用户授权范围内执行。

## 二、不能做到的（限制与约束）

### 1. 不能自动登录 / 登录态极脆弱
- **不能**自动输入账号密码或短信验证码；只能复用用户在 Chrome 里**已登录**的会话。
- 来客/生意经的登录会话 cookie（`sessionid_*`、`uid_tt_*`、`sid_tt_*`）**关闭 Chrome 后即被清除**，磁盘残留 cookie 无法在重启后恢复登录。
- **约束**：必须让用户在该 Chrome 窗口内当场登录一次，且**取数全程不得重启 Chrome**；会话超时也需重新登录。

### 2. 日期 / 日历组件的技术限制（高频踩坑）
- **视频管理页（list-v2）无「自然月」按钮**，只有「昨天/近7日/近30日」；自定义日历对焦点极敏感，eval 触发后自动关闭、纯 ref 点击外层日期 div 的 onclick 也不生效 → **短视频明细只能取「近30天滚动窗（如 06-15~07-14）」**，无法稳定锁定日历自然月。
- **直播专业版「自然月」预设实为 30 天滚动窗（如 06-16~07-15）**，并非日历 7 月；日期框为**只读展示**，`fill` 无效、点击不弹日历 → 只能**逐页翻页**后按开播时间过滤出 7 月场次。
- 生意经**「自定义」日历**：**已自动化打通（用户发截图教学，2026-07-15）**——点统计周期旁日历图标 → 快捷选项「自定义」→ 双月面板（日期格子有 `@eN` ref 可直接 click）→ 选起止 → 确认。详见 `references/user-taught-methods.md` 方法一。**视频管理页 / 直播专业版 的日期框仍是真实限制**（见本段其余条目），仅生意经数据中心日历已通。
- 图表区「近7日/近30日/自定义」快捷选择器**仅支持 ≤1 个月**范围，选不了跨月长区间。

### 3. 下载 / 导出在沙箱中的限制
- 直播专业版「**下载明细**」按钮：沙箱浏览器**静默拦截 blob 下载**，无任何文件落盘（含 Downloads、浏览器 user-data-dir 均查无）→ 改用**逐页快照 + Python 正则解析**取数。
- `normalize.py` 的 Excel 输出**依赖 `openpyxl`**；未安装则自动回退 CSV（不报错，但拿不到 xlsx）。

### 4. 页面交互的 React SPA 技术限制
- 来客 / 生意经 / 直播专业版均为 React SPA：
  - 左侧导航 `$AB click @eN` **常不触发路由**（子节点 click 无效）→ 必须 `eval` 对**文本节点父级** `dispatchEvent(mousedown/mouseup/click)`。
  - 下拉子菜单（如 投放→投放分析）需**先 hover（pointerenter/mouseover）**再点子项。
  - 分页 `<li>`（如全部场次第 N 页）`click @eN` 不触发 React 路由 → 需 `eval` 取末个匹配 `li` 并 `dispatchEvent(pointerdown/mousedown/mouseup/click)`。
- **元素 ref 每次 `snapshot` 重新编号**，绝不能硬编码 `@eN`；每次操作前须重新定位。
- **agent-browser 的 `eval` 复用同一执行上下文**，`const x` 会残留报 `already declared` → 所有 eval 必须用 **IIFE `(()=>{...})()`** 包裹。

### 5. 数据覆盖与口径限制
- **人群模块「自然月」仅支持首购用户数据**；回购/多单/地域分布常需近7/近30日口径，无法用自然月取全。
- 部分指标（如成交券数、退款率 95%+ 等）生意经汇总页不直接给，需进「交易查询」或模块详情。
- **历史对比/趋势/同比需要持续 `collect` 历史记录**：首次使用只有当期数据，月/季/年复盘的对比与趋势会在有历史记录后自动补全。
- 生意经「流量概览」的「自然月」键**此前实测曾点错位置而误判失效**，正确做法是点页面级日期快捷键（非卡片内小选择器）。

### 6. 环境与依赖约束
- 本环境 `agent-browser` **不在 PATH**，须用 `node` 直接跑入口脚本并指定系统 Chrome（`CHROME_PATH`）；`browser-use` CLI 仅含文档未安装，**以 agent-browser 为准**。
- 依赖特定 node 路径与 Chrome 路径；脚本 `aggregate.py`/`normalize.py` 用 Python 标准库即可，但 Excel 输出需 `openpyxl`。
- 仅支持 PC 端来客后台 / 生意经 / 直播专业版 Web；**不支持 App 端、小程序、Douyin 主端**数据。

### 7. 不适用场景
- 不涉及来客后台的**写操作**（上架商品、改价、发起退款、回复评价等）。
- 不替代专业 BI / 官方数据 API；本技能是「复用登录态 + 浏览器抓数 + 本地规整」的轻量方案，适合代运营/复盘取数，不适合高并发或程序化长期采集。
- 无法突破平台反爬/风控：若账号被风控或需滑块验证，需用户人工处理。

## 三、人机协作约定（用户补位机制，2026-07-15 确立）

> 核心原则：**凡是自动化触达不到的按钮 / 页面，由用户手动操作，agent 再继续读取数据。**
> 这把上文多数「不能做到」项转化为「用户操作 + agent 读取」的可行路径，是本技能在真实环境跑通的关键协作方式。

### 哪些环节交给用户手动操作（agent 暂停并给出明确指引）
| 环节 | 为什么自动化难触达 | 用户需做的操作 |
|------|--------------------|----------------|
| **登录 / 续期会话** | 不能输验证码；cookie 重启即丢 | 在指定 Chrome 窗口内完成手机号+短信验证码登录，保持窗口不关 |
| **生意经「自定义」日历（月/季/年/周复盘起止日）** | 此前误判需手动；**用户发截图教学后已自动化打通**（方法一） | 一般无需用户；仅视频管理页 / 直播专业版日期框仍受限时才需用户手动或翻页解析 |
| **视频管理页自然月日期 / 直播专业版日期框** | 无自然月键 / 日期框只读 | 手动设好目标日期范围，再由 agent 读取 |
| **「下载明细 / 导出」按钮** | 沙箱拦截 blob 下载，无文件落盘 | 手动点导出并把文件放到约定目录，或放弃导出改由 agent 翻页解析 |
| **滑块验证 / 风控拦截** | 平台风控，自动化无法绕过 | 用户人工通过验证后通知 agent 继续 |

### agent 的执行约定
1. **遇阻即停，不瞎猜**：一旦确认某元素（日历、下载、登录、风控）自动化无法稳定触达，**立即停止重试**，向用户说明「需要你手动操作 X」，并给出具体步骤/位置。
2. **给精确指引**：说明在哪个页面、点哪个入口、设什么值（如「生意经经营概览 → 右上角自定义 → 设 2026-06-01~06-30」）。
3. **用户操作后继续**：收到「设好了/登录好了」后，agent 重新 `snapshot` 定位、读取数据并续跑后续流程。
4. **优先降级方案**：若用户不愿手动导出文件，agent 走翻页快照 + 本地解析（如直播专业版82场明细）兜底，不必强求下载。
