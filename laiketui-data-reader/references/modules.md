# 抖音来客后台模块与字段映射

> 用途：为 `laiketui-data-reader` 提供各数据模块的入口、关键字段与字段标准化映射。
> 注意：来客后台 URL 与导航文案会随版本变化。以下为 2025–2026 常见形态，实际以 `browser-use state` / `screenshot` 确认的页面为准。

## 1. 登录入口（先确认）
- 主入口（PC 商家后台）：`https://life.douyin.com/p/login`
- 核销数据备用域名：`https://laike.douyin.com`（部分账号/旧版）
- 登录方式：手机号验证码 / 主账号扫码（**不可自动化输入**，须复用用户 Chrome 登录态）

## 2. 顶部导航 / 模块地图
登录后常见导航：首页 · 门店管理 · 团购管理（团购商品）· 营销中心 · 数据中心（生意经）· 订单 · 评价管理。
部分账号把"数据中心"细分为：流量、成交、核销、退款、复购、人货场、门店排名、效果归因。

## 2.5 实战版：生意经数据中心（life-data.cn，已实测跑通）
> 商家真正的经营分析在**独立域名 `life-data.cn` 的「生意经官方数据平台」**，从 `life.douyin.com` 顶部导航「生意经」进入会跳转过去。
> 门店管理员账号进入后有**商户选择弹窗**，需搜索/选中目标商户（如「青石峡漂流」）才能进该商户数据中心。以下为实测的真实模块结构与字段。

### 2.5.0 四维度复盘的周期与日期范围
数据中心的"自定义"日历按以下范围设定（边界由 `scripts/aggregate.py period` 统一计算，避免手工算错）：

| 复盘类型 | key 形式 | 时间窗（示例） | 说明 |
|----------|----------|----------------|------|
| 周 `week` | `week/YYYY-MM-DD` | 上周一~上周日（07/06~07/12） | 自然周（周一至周日） |
| 月 `month` | `month/YYYY-MM` | 上月 1 日~月末（06/01~06/30） | 自然月 |
| 季 `quarter` | `quarter/YYYY-Qn` | 上季首月 1 日~末月末（Q2: 04/01~06/30） | 自然季 Q1=1~3月… |
| 年 `year` | `year/YYYY` | 上年 1/1~12/31（2025-01-01~12-31） | 自然年 |

> `--completed` 语义：取"上一完整周期"；不传则取含参考日的当期。

> ⚠️ **日期范围 UI 实测限制（关键）**：数据中心的日期选择有**两套入口**，能力不同——
> - 图表区附近的「近7日 / 近30日 / 自定义」快捷选择器：仅支持 **≤1 个月** 的范围，选不了跨月的长区间。
> - 页面**右上角的「自定义」**：可手动选择 **>1 个月** 的任意时间范围（月 / 季 / 年复盘必须用它）。
> 因此：周（≤7日）用快捷选择器即可；**月 / 季 / 年复盘必须请用户在右上角「自定义」手动设好起止日**，自动化点击该控件常因 React 合成事件弹不出，最稳妥是用户手动设好后由 agent 读取。

### 2.5.1 经营概览（经营标签）
- 成交金额（GMV）
- 核销金额
- 退款金额
- 预约金额
- 成交/核销券数（需点进「交易查询」或概览详情才显示）

### 2.5.2 流量（流量标签）
- 线上曝光次数（总）
- 门店页访问人数
- **流量来源表**（按来源拆分，每行含）：
  - 直播：直播间曝光人数、直播成交金额、直播核销金额、直播转化率
  - 视频（短视频）：视频曝光、视频成交金额、视频核销金额
  - 搜索：搜索曝光人数、搜索成交金额、搜索核销金额、搜索转化率

### 2.5.3 内容分析（内容标签，含直播/视频明细）
- **直播分析**：直播间成交金额、直播核销金额、直播退款金额、**直播时长（秒，需 ÷3600 换算小时）**、**直播场次数**、直播间曝光人数、直播间观看人数、曝光→成交转化率、观看→成交转化率
- **视频分析**：短视频成交金额、视频播放量、**种草价值**、视频成交券数、视频转化率

### 2.5.4 人群资产（人群标签）
- 新客成交数 / 老客成交数
- 复购人数 / 复购率（近7天）
- 人群画像：年龄分布、性别、城市层级、消费力标签（如"24-40岁中高消费力精致妈妈"）

### 2.5.5 评论/评价
- 新增好评数、新增中差评数（入口可能在「评价管理」或内容/人群模块，按页面实际定位）

## 4. 字段标准化映射（供 normalize.py 使用）
normalize.py 会把下列中文表头归一为标准英文键（不区分大小写、忽略空格与标点）：
- 商品名称/套餐名/名称 → product_name
- 商品ID/券ID/ID → product_id
- 状态/在售状态 → status
- 售价/价格/券价 → price
- 销量/售出量/售出 → sold_count
- 收款/实收/金额 → amount
- 核销数/核销量 → verified_count
- 退款数/退款 → refund_count
- 核销率 → verify_rate
- 退款率 → refund_rate
- 核销金额 → verified_amount
- 待核销金额 → pending_verify_amount
- 订单号/订单ID → order_id
- 订单状态 → order_status
- 支付金额 → pay_amount
- 核销时间 → verified_at
- 门店/门店名 → store_name
- 达人/达人昵称 → talent_name
- GMV/达人GMV → gmv
- 佣金 → commission
- 结算状态 → settle_status
- 评分/星级 → rating
- 评价内容 → review_text
- 评价时间 → review_time
- 回复状态 → reply_status

## 5. 取值健康参考（用于复盘解读，非强制）
- 核销率：团购类目建议 ≥ 60%，低于 40% 需复盘
- 退款率：建议 ≤ 10%
- 待核销金额：低于总销售额 40% 为健康
- 新客占比：团购活动建议 ≥ 30%
- 分析周期：以 7 天为单位横向对比，避免单看某一天

## 7. 四维度复盘：四类数据字段映射

任意复盘（周/月/季/年）都必须覆盖下面**四类数据**，缺一类即不完整。统一数据模型见 `review-schema.md`。

### 7.1 统计数据（stats）
即本周期从生意经各模块抓取的核心指标（=第 2.5 节全部字段），其英文键见 `review-schema.md` 第 6 节指标全集（gmv / verified_amount / coupon_sold / exposure / live_gmv / video_views / search_gmv / new_customers / repurchase_rate / good_reviews …）。

### 7.2 对比数据（comparison）
| 子类 | 对照周期 | 生意经取数位置 | 指标键后缀 |
|------|----------|----------------|------------|
| 环比 `qoq` | 上一相邻周期 | 开启页面「对比」开关 → 读"较上一周期"delta | `_qoq_pct` |
| 同比 `yoy` | 去年同期 | 开启页面「对比」开关 → 读"较去年同期"delta | `_yoy_pct` |

> 若页面未直接给 delta，`aggregate.py review` 会从已存的上一周期/去年同周期记录自动计算环比/同比，无需重复抓取。

### 7.3 趋势分析（trend）
| 复盘类型 | 趋势粒度 | 默认子周期数 N |
|----------|----------|----------------|
| 周复盘 | 周 | 8 周 |
| 月复盘 | 月 | 12 个月 |
| 季复盘 | 季 | 8 季 |
| 年复盘 | 年 | 5 年 |

取数：把日期范围拉到对应长窗口，读取逐子周期的同一指标序列（或由历史多条记录拼接）。序列最末点 = 当前复盘周期。

### 7.4 目标完成度（goal）
- 目标值来源：`config/targets.json`（按 `客户 → 周期类型 → 指标键` 配置），由运营维护。
- 完成率 = 实际值 / 目标值 × 100%。
- 未配置目标的指标完成率标记"未设目标"。

## 8. 复盘模板扩展到月 / 季 / 年

周复盘模板的字段（见第 6 节）在月/季/年复盘中**字段完全相同**，仅时间窗放大、且额外补充四类数据：

| 维度 | 时间窗 | 在周模板基础上增加的输出 |
|------|--------|--------------------------|
| 周复盘 | 上周 | 基础模板字段 |
| 月复盘 | 上月 | + 环比( vs 上月) / 同比( vs 去年同月) / 12个月趋势 / 月度目标完成度 |
| 季复盘 | 上季 | + 环比( vs 上季) / 同比( vs 去年同季) / 8季趋势 / 季度目标完成度 |
| 年复盘 | 上年 | + 环比( vs 前年) / 同比( vs 前年) / 5年趋势 / 年度目标完成度 |

**话术模板（月/季/年可直接套用，把"周"换为对应周期，并附对比/趋势/目标三节）：**
```
哈喽各位老板，以下是门店【<周期，如 2026年6月>】整体数据复盘

【成交数据】成交GMV / 核销金额 / 成交券数 / 核销券数
【对比数据】环比（vs 上一<周期>）GMV ±x% / 核销 ±x%；同比（vs 去年同<周期>）GMV ±x%
【人群数据】新客/老客成交数、复购率、主要客群画像
【流量数据】线上曝光、直播(成交/核销/时长/场次)、视频(成交/播放/种草)、搜索(成交/核销/曝光)
【趋势分析】近 N 个<子周期> GMV / 核销走势
【目标完成度】GMV 实际/目标 = x%（未设目标则略）
【评论数据】新增好评 / 中差评
以上数据请您查收~
```
> 月/季/年复盘建议把"同比""趋势""目标完成度"单独成节，比周复盘信息密度更高，便于老板看长期走势与年度目标进度。
