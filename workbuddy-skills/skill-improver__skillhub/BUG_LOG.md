# BUG 与修复日志

本文件用于记录 skill-improver 在改进过程中发现的问题和自行修复方案，形成持续进化的反馈闭环。

## 使用说明

- 每次执行改进任务时，先读取本文件获取历史问题上下文
- 发现新 BUG 或执行临时修复时，将记录追加到对应 skill 条目下
- 当某个 skill 的 BUG 积累到一定数量时，在下次改进任务中触发批量修复
- 已修复的 BUG 标记状态为 `[已修复]`，并记录修复日期和方案

## 日志格式

每个 BUG 条目格式如下：

```
### [BUG-YYYYMMDD-NN] 简短描述
- **发现日期**: YYYY-MM-DD
- **目标 Skill**: skill-name
- **严重程度**: 高/中/低
- **现象**: 具体的问题表现
- **临时修复**: （如有）执行过程中采用的绕过方案
- **根因分析**: 问题的根本原因
- **修复方案**: 建议的修复方案
- **状态**: [待修复] / [已修复]
- **修复日期**: （修复后填写）
```
