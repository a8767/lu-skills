# 记忆宫殿记忆法 (Memory Palace Method)

> 你的个人知识助手 - 让笔记自动成长迭代

## 🎯 这是什么？

一个自适应个人知识管理系统。无论你是：
- 笔记新手 → 帮你建立结构
- 笔记达人 → 帮你优化整理
- 团队管理者 → 帮你沉淀经验

**核心**：不是固定9层，而是分析你的现有笔记，找到最适合你的结构。

## ✨ 核心功能

### 🔍 智能分析
- 深度扫描工作区所有笔记文件
- 分析你的笔记组织方式
- 发现规律和特点

### 🎯 个性推荐
- 根据分析结果推荐最佳结构
- 层数：3-12层可选
- 每层名称可自定义

### ✅ 你做主
- 分析结果仅供参考
- 最终由你决定结构
- 随时可以调整

### 🔄 自动成长
- 每日凝练：当日记录自动归档
- 每周提炼：提取精华到总结
- 每月迭代：优化结构

## 🚀 快速开始

### 1. 安装
将技能复制到你的OpenClaw技能目录。

### 2. 首次使用
首次运行会：
1. 扫描工作区的笔记文件
2. 分析现有结构
3. 生成推荐方案
4. 等待你确认

### 3. 确认结构
根据分析结果，你可以：
- ✅ 直接确认
- ✏️ 修改层数/名称
- ➕ 添加新层
- ➖ 删除不需要的层

## 📖 使用说明

### 命令

```bash
# 首次分析
python3 scripts/analyze.py

# 查看状态
python3 scripts/analyze.py --status

# 手动凝练
python3 scripts/condense.py --daily    # 每日
python3 scripts/condense.py --weekly   # 每周
python3 scripts/condense.py --monthly  # 每月
```

### 配置

编辑 `.palace/config.json`：
```json
{
    "layers": 6,
    "layerNames": ["收件箱", "项目", "技术", "经验", "归档", "精华"],
    "refineSchedule": {
        "daily": "23:00",
        "weekly": "sunday",
        "monthly": "last"
    }
}
```

## 💡 常见问题

**Q: 我有很多笔记，但很乱怎么办？**
A: 技能会扫描所有笔记，分析规律，给你推荐最合适的结构。

**Q: 我是新手，不懂什么结构？**
A: 没关系，技能会根据内容类型自动推荐，你确认就行。

**Q: 以后想改结构怎么办？**
A: 随时可以重新运行分析，调整结构。

## 📋 原则

1. **适应你** - 不是固定结构，灵活调整
2. **你做主** - 建议仅供参考，决定权在你
3. **自动成长** - 持续优化，越用越好
