# lu-skills

个人技能归档仓库，分目录保存 WorkBuddy 与 Codex 技能。

## 目录

- [workbuddy-skills/](./workbuddy-skills/)：71 个 WorkBuddy 技能包。
- [codex-skills/](./codex-skills/)：56 个 Codex 用户技能包，包含 62 份 SKILL.md；见[技能清单](./codex-skills/README.md)。

## 安装 WorkBuddy 技能

在 Windows 上运行 install-skills.ps1（也可双击 install-skills.cmd）；在 macOS/Linux 上运行 install-skills.sh。默认从 workbuddy-skills/ 安装到 WorkBuddy 技能目录。脚本仍支持从备份归档恢复。

## 安装 Codex 技能

将 codex-skills/ 中的技能目录复制到 %USERPROFILE%\.codex\skills\。按需参考各技能目录中的 SKILL.md。

## 公开副本

本仓库面向公开分享。同步时会排除本地环境配置、会话日志、缓存、备份和私人界面截图；少量联系邮箱仅在公开副本中隐去，本机源文件保持原样。
