# 🧠 Memory Recall — 记忆召回

> **作者**：Wyman Ho | **版本**：1.0.0
>
> 新对话启动时，自动召回用户记忆、偏好和项目上下文，让每个新Session都"认识你"。

🧠 **记忆召回** · 💬 **上下文连续** · 🔇 **静默无感**

## 一句话看懂

每次新开对话，Agent 先静默读取你的工作记忆和历史对话，然后像老朋友一样开始服务——你不会感知到这个过程，只会觉得它越来越懂你。

## 工作原理

当新对话/任务启动时，Agent会静默执行4步记忆召回协议：

1. **读长期记忆** — `MEMORY.md`（用户档案、偏好、项目背景）
2. **读近期日志** — 今天 + 昨天的日记文件（近期工作上下文）
3. **搜索历史对话** — 按当前任务语义检索关联的过往对话
4. **综合融入** — 自然地运用已回忆的上下文服务用户

整个过程对用户完全透明——不会说"我正在回忆"，用户只会觉得你每次都很懂他。

## 兼容性

- 需要WorkBuddy IDE环境（提供 `conversation_search` 工具）
- 依赖 WorkBuddy 工作记忆系统（`{workspace}/.workbuddy/memory/`）
- 适用于所有已配置工作记忆的项目

## 安装后效果

安装此Skill后，每次新开对话时Agent会自动触发记忆召回，无需手动操作。
