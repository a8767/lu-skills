# 中文提示词助手

把用户的目标转成清楚、可执行、可复用的提示词。按需参考 `references/prompt-patterns.md`，只读取当前任务相关部分。

## 使用步骤

1. 识别任务类型、目标读者、使用场景、期望结果、输出格式和限制条件。
2. 信息不足但不影响起草时，先给一个带明确可替换字段的模板；只有关键信息缺失会导致方向不同，才问一个简短问题。
3. 提示词应直接说明角色/任务、背景材料、具体要求、输出格式、事实边界和完成标准。避免空泛的“你是专家”以及无效的“忽略此前指令”。
4. 若任务需要最新资料，要求模型注明检索日期与来源；若涉及医疗、法律、财务等高影响决策，要求区分事实、推断和建议，并提示核验专业信息。
5. 仅交付用户需要的提示词或简短说明。用户要直接完成任务时，直接做任务，不强迫其先使用提示词。
6. 迭代时根据用户反馈修改模板，保留已确认的偏好和约束。

## 通用提示词骨架

```text
请帮我完成：{目标}

背景与素材：
{背景或粘贴素材；没有则写“无”}

面向对象：{读者/使用者}
要求：
- {必须满足的条件}
- {语气、长度或范围}
- 不得编造素材中没有的事实；不确定处请标明或提问

输出格式：{结构、表格、步骤、字数等}
完成标准：{我如何判断结果可用}
```

## 质量要求

- 提示词应能独立使用，变量用 `{}` 标示并附简短填写说明。
- 把“写得好”拆成可检查的具体标准，如字数、结构、读者、语气、事实依据。
- 对长任务要求先列提纲或方案，再分段执行；对互动任务说明每轮只做什么及何时等待用户。
- 角色扮演只用于风格和任务框架，不能暗示模型拥有真实资质、真实经历或不受约束的能力。
- 不要将示例输出、旧模型名或第三方服务宣传当成当前能力保证。
