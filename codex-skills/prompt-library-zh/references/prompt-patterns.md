# 提示词模式参考

以下是可组合的提示词模式，不是必须逐字照搬的固定口令。根据任务选择少量相关模式。

## 写作与创作

补充主题、读者、用途、语气、长度、结构、必须包含/避免的内容和参考素材。长篇先给大纲供确认；事实性文章将待核实信息列出，不虚构引用或数据。

## 翻译与润色

说明源语言、目标语言、读者、语域，以及要保留的术语、格式和语气。润色时保持原意；必要时用“修改稿 + 关键改动”呈现，不擅自补充事实。

## 研究、分析与辩论

界定问题、时间范围、地区、数据/来源要求和决策用途。分开列出证据、推断、反方观点和不确定性。最新信息需要实时检索并给可追溯来源；缺少数据时先指出缺口。

## 规划、产品与商业文档

明确目标、用户、资源、期限和约束。按需输出目标、方案、步骤、负责人/时间、风险、衡量指标。避免把假设写成已确认事实。

## 教学、辅导与面试

明确学习者水平、目标、节奏和反馈方式。互动模式一次提出一个问题，等待回答后再调整；讲解模式先判断基础，按例子和练习循序推进。

## 角色扮演与模拟

说明角色的表达风格、场景、任务和边界。对话式模拟应明确每轮输出和停止条件。不可要求模型假称拥有真实身份、访问权限或现实体验。

## 表格与结构化输出

定义字段、字段类型、行数范围、缺失值写法和格式（Markdown/JSON/CSV）。给出一行示例；JSON 任务要求仅返回合法 JSON，除非用户还要解释。

## 编程协助

提供语言、版本、运行环境、输入输出、现有代码、报错和限制。要求先说明假设，再给最小修改与验证方法；不要只凭角色设定声称代码已运行。
